# 连续动态谱（单行滚动谱）实施方案

> **决策来源**：用户 2026-11-08 拍板（见 §八）。
> **状态**：M1 引擎（`adj1258`）、M2 宿主渲染（`adj1259`–`adj1263`）、M3 对拍台与出片（`adj1264`）已完成；
> 剩 M4 打磨（主题编辑器、卡片适配、真视频回归）。
> **相关文档**：`docs/DYNAMIC-SCORE-PLAN.md`（多行 + 相机位，另一条路线）、
> `docs/EXTERNAL-ACCOMPANIMENT-PLAN.md`（对拍与 sidecar）、`docs/SYNTAX.md`

## 一、这是什么，和「动态谱视频」有什么区别

| | 现在的动态谱视频 | 连续动态谱（本文） |
|---|---|---|
| 方向 | **竖着滚**（一行一行往下） | **横着滚**（全曲一条线，往左移） |
| 画面 | A4 版面 + 相机取景 | 背景视频 + 一条谱带 |
| 当前音 | 相机把当前行推近 | 谱带左 1/3 的**定位色块** + 跳跳球 |
| 排版 | 原样 A4 | **按时值重排成单行**（反复/跳转已展开） |

**平台**：桌面专属（与动态谱视频同一道闸门 `canUseDynamicVideo()`）。网站 / 插件不给入口。

## 二、总体结构

```
.jps ──parse──▶ layoutScore（会话级：条带字号、时值优先）
                        │
播放序列（已展开反复/跳转）─ barStartsMs / barNos
                        │
        buildLinearStrip()  ← 引擎纯函数（engine/linear/）
         └ 输出：一整页 ScorePage（超宽单行）+ runs + notes(时间→x)
                        │
        renderScoreToSvg → 一张超宽 SVG → 分块光栅（缓存）
                        │
背景视频（Mediabunny 解码）┐
谱带块 + 定位色块 + 跳跳球 ├─▶ draw(ctx, t)  ← 一帧
片头/片尾卡（跟随视频宽高）┘
                        │
           预览：音频时钟驱动     出片：encodeMp4（现成的）
```

三条硬约束沿用：`draw(t)` 纯函数、所有动画由 `t` 算、`t=0` = 第 0 个采样。

## 三、单行谱怎么来（方案 A：坐标重排）

不重排字形，只做**仿射变换**：拿正常排版的结果当底稿，按演奏顺序克隆每个源小节。

- **源小节表**（`engine/linear/measures.ts`）：行 = `rowSpansOfPage`（与试听同一套曲行判定）；
  小节边界 = 行内小节线的 x；元素归属按 x 落点判。**不用 `barIndex`**（它跨 Q 行会重新起算）。
- **按演奏顺序展开**（`strip.ts`）：吃 `seq.barNos` + `seq.barStartsMs`（逐遍记录），
  同一个源小节号出现几次就克隆几次。反复 / 跳房子 / `&ds` / `&dc` / `&fine` 在条带上**不再存在**。
- **横向量纲**：每小节 `k = max(1, 每拍像素 × 本小节拍数 ÷ 源小节自然宽)`——
  只放大不压缩，密集小节按自然宽走（宁可这一段慢一点，也不让字叠在一起）。
- **纵向**：`y' = y − 源行基线 + 条带基线`，多行拼到同一条基线上。

### 3.1 行首小节线（用户特别点出的坑）

排版里行首的普通 `|` **不画**（`layout/index.ts:2101`），`|/` 隐藏线**不显示也不占位**
（`types.ts:295`、`spacing.ts:106`）。⇒ 拼成一条线后，行与行的交界处会**缺一根线**。

规则（已实现 + 断言守着）：

1. 每个小节起点都补一根线，**第一条 run 除外**；
2. 线类型降级：`|: :| :|: |/ |*` → `|`（反复已展开，不再画反复记号）；`|| ||/` → `||`；
3. 曲末若源谱是 `||`，条带末端补一条终止线。

## 四、数据结构

```ts
// engine/linear/types.ts
interface StripRun { sourceBar: number; pass: number; t0: number; t1: number; x0: number; x1: number; pageIndex: number; rowIndex: number }
interface StripNote { t0: number; t1: number; x: number; w: number; sourceBar: number }
interface LinearStrip {
  page: ScorePage          // 合成的一整页（宽 = 全曲、高 = 一行）
  width: number; height: number; baselineY: number
  runs: StripRun[]; notes: StripNote[]
  noteSize: number; pxPerBeat: number; beatMs: number
  dropped: { crossMeasure: number; fragment: number; extraVoice: number }  // 丢了什么，不许静默
}
```

`page` 故意做成 `ScorePage`，这样 `renderScoreToSvg` 能**原样渲染**——
字形、减时线、高低八度点、变音、倚音、歌词全部走既有渲染。

## 五、渲染与合成（M2）

| 层 | 做法 |
|---|---|
| 谱带 | 一次排版、一次出 SVG（超宽）→ `applyRangeToSvg` 按可视窗口裁块 → 缓存成位图块（LRU） |
| 文字色 | `tintSvg(svg, ink)` 把写死的 `#1b1b1b/#333/#555/#888` 换成主题色 |
| 描边/阴影 | 烘焙进块缓存（8 方向偏移描边 + 模糊），不每帧算 |
| 定位色块 | 固定在画面宽 1/3；`scrollX = stripXAt(t) − viewW/3` |
| 跳跳球 | x 固定在色块中心，只在 y 弹；落地 = 拍点（`barStartsMs` 重置网格），复用 `BALL_LANDING_TIMING` / `BALL_SQUASH_*` |
| 背景视频 | Mediabunny `BlobSource` → `VideoSampleSink.samplesAtTimestamps` → `sample.draw()` |
| 片头片尾 | 从 `renderer.ts` 抽出 `cardPainter.ts`，尺寸传视频宽高（`endCardLayout` 已按比例算） |

## 六、对拍台与音频（M3）

**独立台面**（`dialogs/LinearSyncDialog.tsx`，与 `SyncDialog` 同款：Esc 关闭、共用 `syncStore` 与同一份 sidecar），内含：

- 背景视频预览（画布 = **出片分辨率**）+ 谱带 + 定位色块 + 球；
- 波形 + 时间标尺 + 起止点 + 打点 + 微调（复用 `syncStore` / `fitSync` / `syncRuler`）；
- **标记段选择**：下拉列出试听栏的练习段，选中即把保留段对齐到它的起止（`resolvePracticeRange`）；
- 三路音频：视频原声 / 外部伴奏 / 合成音，各带音量；
  **没加单独音频 ⇒ 用视频的音频；加了 ⇒ 用单独那条**（用户 2026-11-08 口径）。

出片：`encodeMp4(session, { fps:30, audio })`，尺寸 = 视频宽高（奇数偶数化）。

### 6.1 落地（`adj1264`）

| 文件 | 做什么 |
|---|---|
| `export/video/linearSync.ts` | **纯函数**：媒体↔谱面时刻、前奏定格、保留段夹紧、混音三档、偶数化、一个音符宽的色块 |
| `export/video/videoSource.ts` | Mediabunny 解码：显示宽高/时长/有无音轨、按"1/30s 时间桶"缓存帧（`warm` + 同步 `drawFrame`）、音轨整条解成 `AudioBuffer`；失败一律返回人话 |
| `export/video/linearExport.ts` | 混音（`OfflineAudioContext`，三路各自音量、合成音按 `offsetMs` 延迟、按拍速变速）+ 调 `encodeMp4` |
| `export/video/mp4.ts` | 参数放宽为 `EncodableSession`（`width/height/totalMs/draw` + 可选 `warm`）：相机位与单行谱**共用同一条编码循环** |
| `dialogs/LinearSyncDialog.tsx` | 台面本体（导入视频/背景图/底色、播放、打点、起止点、标记段、三路音量、主题/谱带位置、出片） |
| `export/video/stripTheme.ts`（`adj1265`） | 主题预设 + **自定义覆盖**（每项独立钳制）、取色器色串换算 |
| `export/video/cardPainter.ts`（`adj1265`） | 片头/片尾卡的画笔（从 `renderer.ts` 抽出，尺寸全按 `W×H` 算）——相机位与连续谱**共用同一份** |
| `export/video/linearSession.ts`（`adj1265`） | 会话时间轴扩成三段 `[片头][导出段][片尾]`；卡片与谱面走同一条 `draw(t)` |

**四条口径决定**（写进代码注释与断言）：

1. **定位色块 = 一个音符宽**（用户 2026-11-09）——宽度 = `字号 × 0.62 × 谱带缩放`，**固定**，
   不随时值/段落变化；原来是 `谱带高 × 0.55`（一块罩住三四个音，看不出"当前是哪个音"）。
2. **视频只记名字**（`sidecar.video`）：几十上百 MB 的视频不复制、不写死路径；
   下次打开提示"上次用的是 xxx，请重新选择"。
3. **解码失败不黑屏**：`VIDEO_ERRORS` 三档人话（认不出来 / 没有画面轨 / 编码解不了），
   帧没到时先铺底色并显示"这一帧还没解出来"；没有视频时纯色/背景图兜底。
4. **同一个 t 画两次一致**：视频帧按时间桶缓存，谱带块按 LRU 缓存；`draw` 里没有任何时钟/随机量。

### 6.2 卡片适配（`adj1265`，M4）

- **卡片在音乐两头**：会话时间轴 = `[片头 introMs][导出段 range][片尾 endMs]`（默认 2s / 2.5s），
  音乐段只覆盖**导出段**——与出片完全一致；不带卡片时 `intro = end = 0`，会话时刻 = 媒体时刻（旧行为不变）。
- **一套版式，三种宽高比**：`cardPainter` 只吃 `W/H`，字号按 `min(W,H)`、位置按比例（`endCardLayout` 已按
  tall/wide/square 分支）⇒ 手机竖屏 1080×1920、横屏 1920×1080、方图 1080×1080 都不裁切、不溢出。
- **音频补静音**：带卡片时音轨两端各补一段（`headMs = 片头` / `tailMs = 片尾`），否则播放器按音轨算时长，
  卡片段会"没有声音轨"、整体时长也被算短。
- **手机竖屏（带旋转元数据）**：`drawFrame` 必须用 `VideoSample.displayWidth/Height`（含旋转），
  不能用 `squarePixelWidth/Height`（旋转前）——否则 cover 会按 1920 宽算，画面被放大 3 倍裁切（`E-2026-562`）。

### 6.3 配色随卡片模板（`adj1266`，M5）

用户 2026-11-09 拍板「**配色随卡片模板**」，所以配色不再是"预设里挑一套"，而是：

| 项 | 取法 | 为什么 |
|---|---|---|
| 墨色 | 卡片 `title.from` | 深底模板本来就配亮字、纸面配墨字，这是卡片自己"在底上可读"的答案 |
| 描边 | 深底黑边 / 浅底白边（半透明） | **它才是任何背景都读得清的保险**：纸面模板的墨字落在深色视频上也不会糊 |
| 色块 / 跳跳球 | 卡片 `accent` | 片子的高亮色与卡片同一支，画面才像一个整体 |
| 色块浓淡 | 浅底 0.18 / 深底 0.22 | 与四套预设同一量级，不抢字 |

实现口径：

- `stripTheme.ts` 新增 `stripStyleFromCard(card)`（纯函数）与 `stripBaseStyleOf(theme, card)`，
  **`theme` 缺省 = `auto` = 跟卡片**；四套预设（night/paper/gold/brand）仍可选，明确选了就不跟卡片。
- 界面「配色」下拉第一项是 **跟随卡片模板（模板名）**；选它时 sidecar **不写 `theme` 字段**
  （缺字段即 auto ⇒ 旧文件天然兼容，也不必为默认值往每份文件写字符串）。
- 自定义覆盖（`linear.style`）照旧叠在基准之上；sidecar 解析时的"与基准相同就丢弃"也改用
  **卡片模板的调色板**当基准（`resolveCardStyle(card.template, [])`；用户自建模板在 L1 模板库、
  sidecar 层拿不到，退回默认模板——只影响判重，不影响画出来的颜色）。
- **卡片时长保持固定**（片头 2s / 片尾 2.5s，与相机位一致）：用户拍板"先按固定"，不做可调输入框。

### 6.4 歌词与遍次（`adj1267`，M6）

P2 原话是「歌词可开关，默认只显示第 1 条 `C:` 行；**第 N 遍显示对应歌词行**以后再做」。
`adj1267` 把后半句补上，并把"第 N 遍"的口径定死（三条都不是显然的，写下来免得以后改回去）：

| 口径 | 取法 | 为什么 |
|---|---|---|
| **N = 这个源小节第几次被演奏** | `StripRun.pass`（同一个小节号出现第几次） | 用"整首第几遍"会串词：只反复一小段时（`… \|: 3 :\| 4`），第 4 小节也处在第 2 遍里，那段只唱一次，却会被换成第 2 段词 |
| **只认主声部的词行** | `l.id.voice === 主声部` | `C1:`/`C2:` 是按声部写的词，也占 `line` 序号；不筛声部，"第 2 遍"会把第二声部的词搬到主旋律下面 |
| **按曲行统计段数** | 该行 `line > 0` 的最大值 | 某小节只有一个长音、第 2 段词在那儿没有新字，按小节算会让那一小节退回第 1 段（同一句前后两段串词） |

实现口径：

- `engine/linear/strip.ts`：`occurrencesOf` 的 `pass` 改按小节计数；歌词按 `wantLine = min(pass-1, 该行段数-1)` 选行；
  `LinearStrip.lyricLines` = 这首歌最多几段（界面据此提示"按演奏遍次自动换行"）。
- **关掉歌词只少画字、不缩谱带**（`height` 与 `adj1267` 前完全一致）：条带缩放按 `height` 算，
  一变整幅画面连字号一起跳。
- sidecar 只记**关掉**这一笔（`linear.lyrics = false`；缺字段 = 画），与 `theme` 缺省即 `auto` 同一口径。
- 顺带修掉 `E-2026-569`：歌词归属改按**它挂的那个音符**判（原来按字左缘 x 判，全曲第一个字被丢）。

**`adj1263`（第一次看真图）修掉的四个硬伤**（都在"断言全绿、肉眼看才现形"这一类）：

1. 条带 SVG 带着引擎的**整页白底**（`<rect data-page-bg>`）⇒ 背景视频被一条白带挡住，

2. 减时线**跨小节**：`computeBeams()` 按 `y|barIndex` 分组，条带把所有行压到同一条基线（y 全一样）
   又原样继承了源小节的 `barIndex` ⇒ 整行并成一组，实测冒出 1469px / 2912px 的长横线。
   现在 `cloneNote` 给每段 run 重编 `barIndex`。
3. 歌词墨色 `#101010`（及 `#999`/`#8a8a8a`）没登记进 `STRIP_INK_COLORS` ⇒ 深色背景上歌词是黑字，
   几乎看不见。现在清单补全，并有"清单必须覆盖 SVG 里所有 fill"的闸门。
4. 定位色块画在谱带**之后**（盖在字上）⇒ 当前音被染成粉色。现在色块先画（当底衬高亮），字保持原色。
